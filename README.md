# trip-planner

אפליקציית תכנון טיולים בחו"ל: ימים, נקודות, לינה, מפה ומסלול בגוגל מפות. עברית, מותאמת לטלפון, עובדת בלי אינטרנט.

- הנתונים: `data/*.json` (ראו `CLAUDE.md` לפירוט המבנה).
- מפה: Leaflet + OpenStreetMap (ב-`vendor/leaflet`, רישיון BSD-2).
- הרצה מקומית: `python3 -m http.server` ולפתוח http://localhost:8000.
