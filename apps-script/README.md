# חיבור Google Sheets

הגדרה חד-פעמית, בערך 10 דקות. עדיף במחשב.

## 1. יצירת הגיליון
1. נכנסים ל-https://sheets.new (נפתח גיליון חדש בחשבון הגוגל שלך).
2. נותנים לו שם, למשל "טיולים".

## 2. הדבקת הסקריפט
1. בגיליון: **תוספים ← Apps Script** (Extensions ← Apps Script).
2. מוחקים את כל מה שכתוב בעורך.
3. מדביקים את כל התוכן של הקובץ [`Code.gs`](Code.gs).
   ב-GitHub: פותחים את הקובץ ולוחצים על כפתור ההעתקה (Copy raw file).
4. שומרים (💾 או Ctrl+S).

## 3. יצירת הלשוניות
1. בסרגל העליון, ברשימה ליד "הפעלה" (Run), בוחרים **setup** ולוחצים **הפעלה**.
2. גוגל יבקש הרשאה: **בדיקת הרשאות ← בוחרים את החשבון**.
   אם מופיע "Google hasn't verified this app": **מתקדם (Advanced) ← Go to … (unsafe)** ← **אישור**.
   זה הסקריפט שלך, שרץ על הגיליון שלך בלבד.
3. חוזרים לגיליון. אמורות להופיע הלשוניות: קישורים, מלונות, רכב, טיסות, הגדרות.

## 4. קביעת סיסמאות
בלשונית **הגדרות**, משנים את שני הערכים בעמודה B:
- **סיסמת טיול**: לשותפים לטיול. מציגה גם מספרי הזמנה.
- **סיסמת עריכה**: לך (ולמי שמותר לו לערוך). מאפשרת גם להוסיף ולמחוק מהאפליקציה.

אפשר להחליף אותן מתי שרוצים. השינוי משפיע מיד.

## 5. פרסום הסקריפט
1. בעורך Apps Script: **פריסה (Deploy) ← פריסה חדשה (New deployment)**.
2. ליד "בחירת סוג" (⚙️): **אפליקציית אינטרנט (Web app)**.
3. **הפעלה בתור (Execute as)**: אני (Me).
   **למי יש גישה (Who has access)**: כל אחד (Anyone).
4. **פריסה (Deploy)**. מעתיקים את **כתובת אפליקציית האינטרנט** (Web app URL). היא נגמרת ב-`/exec`.
5. שולחים את הכתובת הזו ל-Claude. **את הסיסמאות לא שולחים.**

בדיקה: פתיחת הכתובת בדפדפן מציגה טקסט שמתחיל ב-`{"ok":true`.

## עדכון הסקריפט בעתיד
אם Claude משנה את `Code.gs`: מדביקים מחדש, שומרים, ואז **פריסה ← ניהול פריסות ← ✏️ ← גרסה: גרסה חדשה ← פריסה**.
ככה הכתובת נשארת אותה כתובת.

## ייבוא מהמייל (Gmail)
באפליקציה, במסכי מלונות / טיסות / רכב, עם סיסמת העריכה: ➕ הוספה ← "מילוי אוטומטי מהמייל". מקלידים את כותרת מייל האישור, והטופס מתמלא. בודקים ומשלימים לפני שמירה.
- הסקריפט מחפש ב-Gmail של החשבון שבו נמצא הגיליון, ומחזיר רק את השדות שחילץ, לא את המייל עצמו.
- פעם אחת: בעורך בוחרים **authorizeGmail** ← **הפעלה** ומאשרים גישה ל-Gmail. גוגל מציג הרשאה רחבה (קריאה, שליחה ומחיקה), אבל הקוד רק קורא.
- מספרי הלילות לא מתמלאים: בוחרים את הימים בטופס.
- לינק "ניהול הזמנה" מהמייל לא מועתק, כי הוא מכיל קוד גישה אישי.

## איך ממלאים
- עמודת **טיול**: `iceland` (או השם, `איסלנד`).
- **מזהה**: משאירים ריק. הסקריפט ממלא לבד.
- **מלונות ← לילות**: מספרי הימים במסלול, למשל `3` או `4,5` או `6-8`. המלון יופיע בימים האלה.
- **מלונות ← קואורדינטות**: לא חובה. `64.14, -21.94` (מגוגל מפות: לחיצה ארוכה על המקום).
- עמודות שמתחילות ב-🔒 מוצגות רק עם סיסמה.
- **לא לשמור** מספרי דרכון או פרטי אשראי.
